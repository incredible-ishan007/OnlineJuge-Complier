Problem 001 — Two Sum

Problem Statement

Given an array of integers nums and an integer target, find two distinct
elements in the array whose sum is equal to target.

Print the 0-based indices of the two elements.

You may assume that exactly one valid pair exists.

The two elements must be at different indices.

Input

The first line contains two integers N and target.

The second line contains N space-separated integers representing the array nums.

Output

Print the 0-based indices of the two elements whose sum is equal to target.

The indices may be printed in any order.

Constraints

2 ≤ N ≤ 100000

-10^9 ≤ nums[i] ≤ 10^9

-10^9 ≤ target ≤ 10^9

Exactly one valid pair exists.

Examples

Example 1

Input

4 9
2 7 11 15

Output

0 1

Explanation

nums[0] + nums[1] = 2 + 7 = 9.


Example 2

Input

3 6
3 2 4

Output

1 2

Explanation

nums[1] + nums[2] = 2 + 4 = 6.


Example 3

Input

2 6
3 3

Output

0 1

Explanation

nums[0] + nums[1] = 3 + 3 = 6.


Note

The order of the two indices does not matter.

For example, for Example 1, both "0 1" and "1 0" are accepted.
