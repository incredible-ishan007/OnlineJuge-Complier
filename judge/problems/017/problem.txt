Problem 017 — Data Stream as Disjoint Intervals

You are given a stream of non-negative integers.

As numbers arrive one by one, maintain a summary of all numbers seen so far using a collection of disjoint intervals.

Two numbers belong to the same interval if every integer between them has appeared in the stream.

For example, if the numbers seen so far are:

1 2 3 6 7

the summary is:

[1,3] [6,7]

Duplicate numbers do not change the summary.

Your task is to process the entire stream and output the final collection of disjoint intervals.

Input

The first line contains an integer n, the number of values in the stream.

The second line contains n non-negative integers:

n
a1 a2 ... an
Output

First print the number of disjoint intervals.

Then print each interval on a separate line in increasing order of its starting value:

number_of_intervals
start1 end1
start2 end2
...
Example 1
Input:
5
1 3 7 2 6

Output:
2
1 3
6 7
Example 2
Input:
5
1 2 3 4 5

Output:
1
1 5
Example 3
Input:
6
5 5 4 7 6 10

Output:
2
4 7
10 10
Constraints
1 <= n <= 30000
0 <= ai <= 10000
Duplicate values may appear.
The output intervals must be sorted by their starting value.
