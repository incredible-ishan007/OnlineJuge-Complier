010. Count of Smaller Numbers After Self

You are given an integer array nums of length n.

For every index i, determine the number of elements to the right of nums[i] that are strictly smaller than nums[i].

In other words, count the number of indices j such that:

i < j < n
nums[j] < nums[i]

Input

The first line contains an integer n.

The second line contains n integers representing the array nums.

Output

Print n integers separated by spaces.

The i-th integer should be the number of elements strictly smaller than nums[i] that occur to its right.

Constraints

1 <= n <= 100000
-10000 <= nums[i] <= 10000

Example 1

Input:

4
5 2 6 1

Output:

2 1 1 0

Example 2

Input:

1
-1

Output:

0

Example 3

Input:

2
-1 -1

Output:

0 0

Equal elements are not considered smaller.
