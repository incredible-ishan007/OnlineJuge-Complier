013. Yura and Deadlines

You are given an array a of length n.

Each position i represents an assignment with weight a[i].

You may choose any subset of assignments. The total score is the sum of the weights of all chosen assignments.

However, two chosen assignments cannot be too close to each other.

For every pair of distinct chosen indices i and j, the following condition must hold:

|i - j| > max(a[i], a[j])

Find the maximum possible total score of a valid subset.

Input

The first line contains an integer n:

1 ≤ n ≤ 2 · 10^5

The second line contains n integers:

0 ≤ a[i] ≤ 10^9
Output

Print a single integer — the maximum total weight of a valid subset.

Example 1

Input

5
3 1 1 1 3

Output

6
Example 2

Input

3
2 1 2

Output

2
Example 3

Input

7
4 1 5 1 1 4 1

Output

8

Note: In the first example, choosing positions 1 and 5 gives 3 + 3 = 6, and they satisfy the required distance condition.
