Problem 005 — Kth Smallest Amount With Single Denomination Combination


Problem Statement

You are given an integer array coins representing different coin denominations and an integer k.

You have an infinite number of coins of each denomination. However, you are not allowed to combine coins of different denominations.

For each coin denomination coins[i], you can make any positive multiple of that denomination.

Return the kth smallest distinct amount that can be made using these coins.

Input Format

The first line contains an integer T, the number of test cases.

For each test case:

The first line contains two integers N and K.
The second line contains N distinct integers representing the coin denominations.
Output Format

For each test case, print the kth smallest amount that can be made.

Constraints
1 ≤ T
1 ≤ N ≤ 15
1 ≤ coins[i] ≤ 25
All coins[i] are distinct.
1 ≤ K ≤ 2 × 10^9
Example 1

Input

1
3 3
3 6 9

Output

9

Explanation:

The amounts that can be made are:

3, 6, 9, 12, 15, ...

Therefore, the 3rd smallest amount is 9.

Example 2

Input

1
2 7
5 2

Output

12

The distinct amounts are:

2, 4, 5, 6, 8, 10, 12, ...

Therefore, the 7th smallest amount is 12.

Important Note

Amounts generated by different denominations are counted only once.

For example, with:

coins = [3, 6]

both coins can generate 6, but 6 appears only once in the sequence of distinct amounts.
